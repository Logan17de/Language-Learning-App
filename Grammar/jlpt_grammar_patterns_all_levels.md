# N5 — 82 patterns

## N5_G001 — だ / です

### 1) Structure
```text
Noun + だ / です
な-adjective + だ / です
い-adjective + です
```

### 2) When to use it
Used to state what something is or describe its condition. だ is plain/casual, while です is polite.

### 3) Example
**Japanese:** 私は学生です。

**English:** I am a student.

## N5_G002 — じゃない / ではない

### 1) Structure
```text
Noun + じゃない / ではない
な-adjective + じゃない / ではない
```

### 2) When to use it
Used to say that something is not something. じゃない is common in conversation; ではない is more formal.

### 3) Example
**Japanese:** 今日は休みじゃない。

**English:** Today is not a day off.

## N5_G003 — だった / でした

### 1) Structure
```text
Noun + だった / でした
な-adjective + だった / でした
```

### 2) When to use it
Used to say that something was a certain thing or condition in the past. だった is plain; でした is polite.

### 3) Example
**Japanese:** 昨日は休みでした。

**English:** Yesterday was a day off.

## N5_G005 — か

